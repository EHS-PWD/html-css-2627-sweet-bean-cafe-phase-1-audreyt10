# ☕ Sweet Bean Café — Website Project

## Project Overview

Congratulations! Your team has been hired as junior web developers to create a website for **Sweet Bean Café**, a new neighborhood coffee shop.

Your goal is to build a **five-page website** that introduces the café, shares its menu, tells its story, explains its coffee membership, and provides contact information.

This is **Phase 1: Website Structure**. Focus on writing organized, meaningful HTML using the skills you have learned in class. You will return to this project later to add HTML tables and forms.

## Learning Goals

By completing this project, you will practice:

- Creating a standard HTML document structure
- Organizing content with semantic elements such as `<header>`, `<nav>`, `<main>`, and `<footer>`
- Using headings, paragraphs, and ordered and unordered lists
- Connecting multiple pages with relative links
- Testing navigation and fixing HTML errors
- Collaborating through mob programming

## Project Folder Structure

```text
sweet-bean-cafe/
├── index.html          # Home
├── menu.html           # Menu
├── about.html          # About Us
├── membership.html     # Membership
├── contact.html        # Contact Us
└── README.md           # Project information
```

## Required Pages

### 1. Home — `index.html`

- Welcome visitors to Sweet Bean Café with an `<h1>`.
- Write an introductory paragraph of at least three sentences.
- Add a **Why Visit Sweet Bean Café?** section.
- Use an unordered list to share at least four reasons to visit.
- Add an **Explore Our Café** section with a link to the Menu page.

### 2. Menu — `menu.html`

- Add an `<h1>` titled **Our Menu** and a short introduction.
- Create a **Coffee** section listing House Brew, Latte, and Cold Brew.
- Create a **Pastries** section listing Chocolate Croissant and Blueberry Muffin.
- Write descriptions of at least two menu items.
- Include a link to the Membership page.

### 3. About Us — `about.html`

- Add an `<h1>` titled **About Sweet Bean Café**.
- Write at least four sentences about how the café began.
- Add an **Our Mission** section with a mission statement.
- Add an **Our Values** section with an unordered list of three values.
- Add an **Our Coffee Beans** section describing Light, Medium, and Dark roasts.
- Include a link to the Menu page.

### 4. Membership — `membership.html`

- Add an `<h1>` titled **Monthly Coffee Box Membership**.
- Explain the membership in a paragraph.
- List at least four membership benefits.
- List the available roasts: Light, Medium, Dark, and Decaf.
- Use an ordered list to explain three steps to becoming a member.
- Include a link to the Contact page.

### 5. Contact Us — `contact.html`

- Add an `<h1>` titled **Contact Us**.
- Write a welcoming paragraph.
- Add a **Visit Our Café** section.
- Include a fictional street address, phone number, and email address as text.
- Add a **Business Hours** section using a list.
- Include a link back to the Home page.

## Shared Structure on Every Page

Every HTML page must include:

1. A standard HTML document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`)
2. A descriptive `<title>` inside `<head>`
3. A `<header>` containing the café name
4. A `<nav>` with working links to **all five pages**
5. A `<main>` containing the page's unique content
6. A `<footer>` with the café name and copyright information

**Tip:** Use relative paths such as `href="menu.html"` when linking between pages in the same folder.

## Teamwork: Mob Programming

You will work in teams of three and rotate roles **every seven minutes**.

| Role | Responsibility |
| --- | --- |
| **Driver** | Types the code and follows the Navigator's instructions. |
| **Navigator** | Gives clear, step-by-step coding directions to the Driver. |
| **Mob** | Reviews the work, looks for errors, and shares suggestions with the Navigator. |

**Rotation:** Driver → Mob → Navigator → Driver

Only the Navigator should give coding instructions directly to the Driver. Everyone should contribute, communicate respectfully, and help test the website.

## How to Run and Test Your Website

1. Open the `sweet-bean-cafe` folder in VS Code.
2. Click the GoLive button on the bottom right hand corner to view in a browser.
3. Click each navigation link and confirm it opens the correct page.
4. Check that every page includes the header, navigation, main content, and footer.
5. Review headings, paragraphs, and lists for correct HTML structure.
6. Fix any broken links or missing content, then test again.
